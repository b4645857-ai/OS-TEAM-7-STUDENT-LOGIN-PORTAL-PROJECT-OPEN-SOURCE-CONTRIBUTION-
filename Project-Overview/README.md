## 📖 Overview

The **Smart Student Attendance & Timetable Portal** is a web-based application developed for educational institutions to digitally manage student attendance and weekly timetables.

The system provides separate functionalities for **Students** and **Faculty**, allowing attendance to be recorded efficiently while giving students real-time insights into their attendance status and eligibility.

# ✨ Features

## 👨‍🎓 Student Module

---

# 🧮 Attendance Analysis

The system automatically calculates:

- Overall Attendance Percentage
- Subject-wise Attendance
- Remaining Classes that can be missed while maintaining **75% attendance**
- Number of classes required to regain **75% attendance**
